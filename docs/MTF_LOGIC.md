# Multi-Timeframe (MTF) Alignment Architecture

## Primary Methodology: M5 Execution + H1 Directional Filter

### 1. Dual-Timeframe Mechanics
1. **Execution Timeframe (M5)**:
   - Primary timeframe for tactical entry timing, FVG mitigation, and local EMA 9/21 cross-examinations.
2. **Directional Filter (H1)**:
   - Evaluates macro institutional bias via the 200 EMA baseline on the 1-hour chart.

### 2. Alignment Matrix Rules
- **Bullish Alignment (YES)**: M5 EMA 9 > 21 > 200 AND H1 Close > H1 200 EMA.
- **Bearish Alignment (YES)**: M5 EMA 9 < 21 < 200 AND H1 Close < H1 200 EMA.
- **Divergence (NO)**: Counter-trend conditions where execution timeframe opposes macro baseline.
